# 🚗 停车小游戏

一个有趣的停车模拟小游戏，使用纯 HTML/CSS/JavaScript 开发。

## 游戏说明

### 目标
将蓝色的车辆停入绿色的停车位中，避免撞到红色的障碍物。

### 游戏特点
- 🎮 使用方向键控制车辆
- ⏱️ 60秒倒计时挑战
- 🏆 得分和关卡系统
- 💥 实时碰撞检测
- 📱 响应式设计

### 控制方式
- **↑ (上箭头)**: 前进
- **↓ (下箭头)**: 后退
- **← (左箭头)**: 左转
- **→ (右箭头)**: 右转

### 游戏规则
1. 点击"开始游戏"按钮启动游戏
2. 使用方向键控制车辆移动
3. 将车辆完全停入绿色停车位（标记为 P）
4. 车辆角度需要基本保持垂直
5. 避免撞到红色障碍物和墙壁
6. 在60秒内完成停车挑战

### 得分系统
- 基础分数: 100分
- 时间奖励: 剩余时间 × 10分
- 例如：30秒完成停车 = 100 + (30 × 10) = 400分

### 如何运行
1. 在浏览器中打开 `parking_game.html` 文件
2. 或者使用本地服务器运行：
   ```bash
   python -m http.server 8000
   ```
   然后访问 `http://localhost:8000/parking_game.html`

### 技术特点
- 纯原生 JavaScript，无需任何框架
- Canvas 2D 渲染
- 实时物理模拟（加速、摩擦力、转向）
- 精确的碰撞检测算法
- 美观的渐变UI设计
